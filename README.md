# Default starter for Gridsome

This is the project you get when you run `gridsome create new-project`.

Install dependencies and start the development server at `http://localhost:8080`.

```sh
pnpm install --frozen-lockfile
pnpm develop
```

The TanStack Start app in [`start/`](start/README.md) has its own lockfile and install commands.

For legacy map tiles, set `GRIDSOME_MAPBOX_TOKEN` locally or in the GitHub Pages workflow's repository secrets. Use a public Mapbox token restricted to the legacy site's URL.
